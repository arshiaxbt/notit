A. Bystander effect - N equal players, all mixedFinalBlock, 2000 independent one-round trials each (seed 1001)
   One extra equal account became It in a setup round and never volunteers. x = player balance, c = final-slot cost, q = c / (cut * x).
   Under the deployed rule only the first volunteer pays, so holders volunteer more readily than in the textbook dilemma.
   Equilibrium p solves q * (1 - (1-p)^N) / (N*p) = (1-p)^(N-1);  P(fail) = (1-p)^N, or 1 if q >= 1.
   The simulation plays that p, so agreement checks the arithmetic and the engine, not that people behave this way.

D. Forward-looking holders - a bound on unsaved rounds when holders value being It
   If being It is worth W at round open and a round goes unsaved with chance pi: W = pi * (cut * S + W), so W = cut * S * pi / (1 - pi).
   Free entry in the final block (a transaction that loses the race costs nothing) forces W <= min_cost * S.
   Bound: pi <= min_cost / (cut + min_cost) = 0.2% / 15.2% = 1.32%, for risk-neutral, equally fast, non-colluding holders.
   Simulated: equal holders, all throneAware, started armed, 500 rounds each (seed 2502).

   throneAware is a rule of thumb, not the equilibrium behind the bound: it prices the throne from the last 20 rounds,
   so where no holder is large enough to save myopically it lets a round fail every 20-odd rounds and exceeds the bound.
